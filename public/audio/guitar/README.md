# Guitar note recordings

`40.mp3` … `85.mp3` are single notes of a steel-string acoustic guitar, named by MIDI note number
(40 = E2, low E string; 85 = C#6).

- **Source:** "Musyng Kite" General MIDI soundfont, instrument `acoustic_guitar_steel`, as pre-rendered
  by [gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts)
  (`https://gleitz.github.io/midi-js-soundfonts/MusyngKite/acoustic_guitar_steel-mp3.js`).

  project is not affected by that license.
